About this project

What this app is, how it was built, and what it does and does not do with your use of it. The audit below backs these claims with evidence.

How this was built

This project was built with AI coding assistance throughout: Claude Code (Anthropic) wrote and iterated on the app itself, its spaced-practice scheduling logic, the content-ingestion tooling used to curate the vocabulary and grammar drills, and this page. Independent AI models (including Gemini and GPT-family models) reviewed the app and its data separately, to catch mistakes the first model might miss in its own work. None of this replaces responsibility for the result.

Commitments

Privacy and no tracking

This app collects nothing about you, and sends nothing anywhere. No analytics, no tracking pixels, no third-party scripts, no cookies. It does use your browser's local storage, on your own device, to remember your practice progress between visits - see the audit below for what that means and how it was checked.

Security

There is no backend, no account system, no form that sends data anywhere, and no database. The app is a single static HTML file with no build step: everything it does runs in your browser, on your device. The entire source is that one file - open it in any text editor, or use your browser's "view source", to read what it does.

No monetization, except a voluntary tip jar

No ads, no paywalls, no affiliate links, no selling of data (there is no data to sell). The only monetization-adjacent thing here is a voluntary Ko-fi link: entirely optional, never required for any feature, and not tied to anything this app knows about you, because it does not know anything about you. Following that link takes you to Ko-fi's own site, governed by Ko-fi's own practices, not this one.

Attribution

Some vocabulary example sentences come from the Tatoeba project, used under the CC-BY 2.0 FR license. This is a license credit, not a network dependency - the sentences are embedded directly in the HTML file, and nothing is fetched from Tatoeba or any other site at runtime.

Method

Checked by reading every line of the page source for script tags, external resource references, cookie or storage API usage, iframes, and network-call code, then separately verified by loading the page in a real browser and recording every network request made, including after clearing and reloading local storage and navigating through the app's tabs, to catch anything a source read-through alone might miss.
